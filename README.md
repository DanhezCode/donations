# Support my work

I build software independently and publish much of my work as open source.

This repository exists for anyone who wants to support that work directly.

**[Support the work →](https://danhezcode.github.io/donations/)**

## Why donations?

Open source lets me keep building and sharing software independently.

That path became important to me because the usual route into remote development was not always practical. I wrote more about that in:

* [The practical side of remote work](https://github.com/DanhezCode/DanhezCode/issues/9)
* [Why I started building independently](https://github.com/DanhezCode/DanhezCode/issues/10)

Today, donations are one of the ways that work can continue.

## What your support does

Your support gives me more room to spend time on the work itself:

* Building and improving open-source software
* Maintaining existing projects
* Research, experimentation, and documentation
* Releases, infrastructure, and ongoing project maintenance

There is a lot of work involved in keeping open-source projects useful, even when that work never becomes a visible feature.
